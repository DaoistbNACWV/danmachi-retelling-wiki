## Profile template

Use this structure for new pages:

1. Name and aliases (only if supported).
2. Story role and first verified appearance.
3. Biography / chronological appearances.
4. Personality and characterization (source-grounded).
5. Relationships (identify each relationship's status and source).
6. Abilities and equipment (exact values only when verified).
7. Current status and last verified location.
8. Knowledge boundaries (what the character knows and how they learned it).
9. Continuity labels and open questions.
10. Sources.

**Critical:** The current level, stats, skills, spells, Familia, injuries, and location must be checked against the latest applicable source. Unknown fields remain `[OPEN]`.
